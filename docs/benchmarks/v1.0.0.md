# DeepVault Benchmark: Version 1.0.0 (Baseline)

## Overview
This document outlines the performance metrics of DeepVault V1.0.0 across four distinct chunking strategies. These results serve as the baseline for evaluating future Hybrid Retrieval and Reranking optimizations.

**Run ID**: `run_20260414_090853`  
**Judge Model**: Llama-3.1-8b-instant  
**Dataset**: 5-Question Golden QA (Balanced Semantic/Research)

## Key Insights
1. **Semantic & Fixed Window Superiority**: Both `fixed` and `semantic` strategies achieved perfect 5.0 faithfulness scores, indicating that for this dataset, simple boundary/semantic boundary alignment provided the clearest context for the LLM.
2. **Structure-Based Trade-off**: While structure-based chunking had the highest **Relevance** (4.4), it suffered from a 20% hallucination rate. This suggests that while it picks the "right" headers, the content within may be too fragmented for complex questions.
3. **Retrieval Stability**: All strategies achieved a 100% hit rate, confirming that the vector store (Qdrant) is correctly indexing and retrieving sources.

## Recommendation
Based on this v1.0.0 baseline, **Semantic Chunking** is the current winner for deep-knowledge retrieval, while **Structure-Based** is best for targeted, specific fact-finding where high relevance is prioritized over narrative faithfulness.
